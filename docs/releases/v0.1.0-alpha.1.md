# VoxQuarry v0.1.0-alpha.1

First public-candidate release: a bilingual, self-hosted review evidence workbench.

- Five functional modules: Data Collection, Products, Reports, AI Research and Settings.
- New Evidence Desk visual system and project identity.
- Local setup/login, same-origin access controls and per-user research ownership.
- Model-free synthetic demo, JSON import, deterministic English-rule reports and original evidence.
- Bounded Walmart/Home Depot collection with explicit partial-source accounting.
- Independent Chinese/English interface and research response controls; bilingual report export.
- Configurable model endpoint, research citations, run records and optional isolated runtime.
- New public Git history, synthetic references, dependency notices and CI checks.

This alpha has local automated and browser verification. Live retailer collection, paid-provider inference and a fresh Docker engine smoke are separate operator checks; they are not certified by the fixture suite. Chinese source text is retained, but equivalent Chinese deterministic analysis is outside this release. Optional PDF/image rendering tests are skipped when their runtime dependencies and font are absent.
