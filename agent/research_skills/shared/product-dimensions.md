# 分析报告分析维度的使用

优先读取匹配的分析报告报告目录与定义，以当前品类和版本为准。下列只是没有适用报告时帮助组织问题的维度，不是必填章节。

- 样本基础：产品及联合 SKU、渠道、时间、正文和评分覆盖、去重方式、使用条件。
- 体验与问题：性能、易用性、续航/能源、质量与服务，正负体验可同现，核对条件和反例。
- 场景与约束：任务、环境、地块/工况、频率、已有工具与平台、期待和实际结果。
- 决策与比较：购买触发、被考虑的替代、关键取舍、前代/竞品差异，缺失环节不补造。
- 机会与建议：影响、涉及样本、潜在可改进点及需进一步验证的假设。

分析报告规则统计是已有分析资产；自主语义判断和补充代码用于当前问题的缺口。没有可信频次时不把定性发现变成精确比例。
