# Security / 安全

VoxQuarry is an alpha intended for a local or carefully configured private workspace. Runtime data and secrets are excluded from the source repository. Authentication, CSRF, capability boundaries and source ownership are tested, but this is not a claim of a completed external security audit.

For a suspected vulnerability, use the repository's private vulnerability reporting feature after it is enabled. Do not attach working credentials, personal data or exploit payloads containing real records to a public issue. Describe affected versions, the minimum synthetic reproduction and expected impact. If private reporting is unavailable, open a minimal issue requesting a private reporting channel without publishing sensitive details.

发现安全问题时，优先使用仓库启用后的私密漏洞反馈入口。不要在公开 Issue 放真实密钥或数据；如私密入口尚不可用，只提交不含细节的联系请求。

Supported security fixes initially target the latest alpha. No response-time or long-term-support commitment is implied.
